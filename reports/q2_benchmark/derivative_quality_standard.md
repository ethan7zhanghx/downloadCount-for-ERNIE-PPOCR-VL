# 衍生模型优质标准

> 撰写日期：2026-04-24
> 数据基准：2026-04-24 HuggingFace 全量采样（近60天内发布，共205,707个模型，55,157个第三方衍生模型）

---

## 一、目标

定义什么样的第三方衍生模型算"优质"，用于 Q2 OKR 中"好的衍生模型数量"指标的统计口径。标准需要满足：

- **可操作**：判断逻辑清晰，能批量执行
- **公平**：不因 ERNIE 生态体量比 Qwen/Gemma 小而系统性地吃亏
- **可向上汇报**：每一条结论都有数据或逻辑支撑

---

## 二、分析范围

**模型来源**：HuggingFace，近60天内发布的全量模型，不做下载量预过滤。

**衍生模型判断（两级，按成本从低到高）：**

- **Level 1**：模型 tags 中存在 `base_model:xxx` 前缀 → 自动识别，提取 base_model
- **Level 2**：无 tag，但下载量 ≥ P90（≥149）→ 名字模式匹配（-GGUF / -AWQ / -GPTQ / -lora 等）

**自引用排除**：衍生模型 publisher 与 base_model publisher 相同的，排除（官方量化/微调自己的模型不算第三方衍生）。

本次采样结果：55,157 个第三方衍生模型。

**模型分类：**

| 类型 | 判断依据 | 数量 |
|------|---------|------|
| LLM | pipeline_tag = text-generation | 21,886 |
| VLM | pipeline_tag = image-text-to-text / vqa / video-text-to-text | 3,973 |
| T2I | pipeline_tag = text-to-image / image-to-image | 2,280 |
| OCR | pipeline_tag = image-to-text / doc-qa / 名字含 ocr | 219 |
| other | 无 pipeline_tag 或其他类型 | 26,799 |

## 三、预筛排除

进入评判前先做一轮机械预筛。满足以下条件的模型直接排除，不进入评判：

**模型卡为空或目的完全无法判断，且下载量未达到优质门槛。**

两个子条件必须同时满足才排除：
1. 模型卡实质为空（无任何有效描述，不含默认模板内容）或模型用途完全不可判断
2. 下载量低于优质门槛（量化 < 500，FT/LoRA < 100）

**设计逻辑：**

- 有用户在用（达到优质门槛）的模型，卡片写得烂也不排除——下载量本身就是价值信号
- 卡片有内容但下载量低的模型（包括下载量为0）也不排除——有可能是给自己用的 FT、或刚发布还没积累下载量，应当进入评判
- 只有"完全没有文档、也完全没有人用"的双重空洞才排除

---

## 四、优质评判框架

### 4.1 三个维度，任一满足即为优质

| 维度 | 含义 |
|------|------|
| **有真实使用** | 有外部用户选择了它，下载量达到门槛 |
| **目的明确** | 为具体场景而做，模型卡说清楚了使用场景和目标任务 |
| **来自真实投入** | 作者认真做了，有可验证的证据 |

三条任一满足即为优质，都不满足但有至少一个值得关注的信号则列为**待跟踪**（标记后定期人工复查），都不满足且无任何信号则不计入。

**待跟踪的含义**：通过预筛、下载量未达优质门槛、但模型卡有实质内容或有其他正向信号，值得后续关注。待跟踪不细分等级，统一人工复查。

### 4.2 各维度的判断方式

**有真实使用：**
- 量化模型：下载量 ≥ 500
- FT / LoRA / T2I LoRA：下载量 ≥ 100

**目的明确：**
- LLM / VLM：读模型卡，判断是否说清楚了使用场景和目标任务
- T2I LoRA：读模型卡，判断是否描述了风格定位或使用场景

**来自真实投入：**
- LLM / VLM 微调：有评测结果——不要求正式 benchmark，有"在 X 任务上达到 Y 效果"即可
- T2I LoRA：同时有 ① 示例图；② 触发词（trigger word）说明
- 量化模型（特殊情况）：为原模型**首次引入**了新的格式支持（如首个 NVFP4 版本、首个 AWQ 版本等）——不考虑下载量，直接视为优质

  **"首次"的判断方式**：查 ERNIE 全量衍生维护表，检索同一 base_model 下是否已有其他模型提供了相同格式（格式粒度：GGUF / AWQ / GPTQ / NVFP4 / EXL2 等大类，不区分精度级别）。若表中不存在同格式的其他衍生 → 首次引入；若已有 → 不适用此条，走正常三维度评判。

## 五、下载量门槛的数据依据

### 5.0 门槛的定位

**下载量门槛是"有真实使用"这一维度的高确信度信号，是充分不必要条件。**

设计目标：过了门槛的模型，可以不看模型卡、不做任何进一步判断，直接确认为优质。因此门槛需要足够高，确保几乎不会把无价值模型误判为优质。

代价是：部分真实有价值的模型下载量未达门槛，它们不会被"有真实使用"这条路捕获，但可以通过"目的明确"或"来自真实投入"两条路进入优质或待跟踪。门槛不需要覆盖所有好模型，只需要对过门槛的模型有高置信度。

### 5.1 分布结构：量化与 FT 是两种完全不同的分布

数据来源：HuggingFace 近60天内发布、发布时间≥30天的全量第三方衍生模型（量化 N=6,820，FT/LoRA N=20,887），不区分模型类别（LLM/VLM/T2I/OCR 统一分析）。

**量化模型：右偏的连续分布，噪音比例低**

| 下载量区间 | 模型数 | 占比 | 累积 |
|-----------|-------|------|------|
| 0 | 295 | 4.3% | 4.3% |
| 1–2 | 303 | 4.4% | 8.8% |
| 3–9 | 739 | 10.8% | 19.6% |
| 10–29 | 939 | 13.8% | 33.4% |
| 30–99 | 1,447 | 21.2% | 54.6% |
| 100–299 | 1,353 | 19.8% | 74.4% |
| 300–999 | 992 | 14.5% | 89.0% |
| 1,000+ | 752 | 11.0% | 100% |

下载量在 log 坐标上大体连续分布，无明显断点。几何均值 89，对数标准差 0.96。0–2 下载的"无效模型"仅占 8.8%，说明量化模型普遍有真实下载行为，噪音比例较低。

**FT / LoRA：双峰混合分布，噪音人群占主体**

| 下载量区间 | 模型数 | 占比 | 累积 |
|-----------|-------|------|------|
| 0 | 6,153 | 29.5% | 29.5% |
| 1–2 | 5,844 | 28.0% | 57.4% |
| 3–9 | 4,151 | 19.9% | 77.3% |
| 10–29 | 1,789 | 8.6% | 85.9% |
| 30–99 | 1,469 | 7.0% | 92.9% |
| 100–299 | 761 | 3.6% | 96.6% |
| 300+ | 720 | 3.4% | 100% |

FT 分布不是单一分布。**57.4% 的模型下载量 ≤2**，形成一个独立的"噪音人群"（作者自用、从未被外部发现、bot 爬取）。3 及以上才代表有外部用户接触到这个模型。

这两个人群性质不同，不能用全量百分位推门槛。

### 5.2 阈值推导

**量化模型**

量化模型是连续分布，目标是找到一个"几乎不会误判"的高置信度位置。

- 几何均值 = 89，代表典型量化模型的下载基准线
- 几何均值 +1σ（对数标准差）= 810，代表"显著高于平均水平"
- 剔除 0–2 噪音后，真实使用人群（N=6,222）的 P75 = 334

在"不需要看模型卡就能确认优质"的充分条件要求下，500 处于 P75（334）和 +1σ（810）之间，是一个保守但合理的高置信度门槛：过了 500 的量化模型，大概率经历了真实的社区发现和使用。

**FT / LoRA**

FT 是双峰混合，要先把问题定义在正确的人群上：阈值不是问"全量 FT 里排到第几"，而是问"在真正有外部接触的模型（3+）里，什么水平代表真实使用"。

- 真实使用人群（3+，N=8,890）的分布：P50 = 11，P75 = 61，P90 = 246
- 100 处于真实使用人群的 P75–P80 之间

100 的含义：在有外部用户接触过的 FT 模型里，超过大约四分之三。这个水平足以区分"有人用过"和"真实社区采用"。

### 5.3 ERNIE 自身历史数据验证

从数据库取每个 ERNIE 第三方衍生模型首次入库后30天的下载量快照（量化 N=234，FT N=100）：

- 量化：P75 = 448，500 对应约 **P76**
- FT：P75 = 55，100 对应约 **P83**

ERNIE 自身历史数据与全量市场推导收敛：量化 500 在 ERNIE 历史里也是 P76 水位，FT 100 是 P83 水位。两个独立数据源互相印证。

### 5.4 公认高质量发布者的分布位置

对 ERNIE-4.5 第三方量化模型，取社区公认发布者入库后30天下载量（仅作定性验证，非推导依据）：

| 发布者 | 模型数 | 中位 | P25 |
|---|---|---|---|
| unsloth | 10 | 450 | 304 |
| mradermacher | 31 | 990 | 310 |
| bartowski | 6 | 4,129 | 182 |
| mlx-community | 41 | 122 | 29 |

可以看到，500 以下确实存在有价值的模型（unsloth 的精度变体、mlx-community 的主力发布）。这与门槛定位一致：这些模型不走"有真实使用"这条路，而是通过"目的明确"或"来自真实投入"进入优质。

---

**最终门槛：**
- 量化：**≥ 500**
- FT / LoRA：**≥ 100**

## 六、完整判断流程

```
给定一个衍生模型
    ↓
【预筛】模型卡为空/目的不可判断，且下载量 < 优质门槛？
    是 → 排除，不计入
    否 ↓
判断类型
    ↓                              ↓
  【量化】                      【FT / LoRA / T2I LoRA】
  下载量 ≥ 500？                 下载量 ≥ 100？
    是 → ✅ 优质                   是 → ✅ 优质
    否 ↓                           否 ↓
  查 ERNIE 全量衍生表：          【目的明确】
  此 base_model 下               模型卡说清楚了使用场景/风格？
  此格式无其他衍生？               是 → ✅ 优质
    是 → ✅ 优质（首次引入）        否 ↓
    否 → 不计入                  【来自真实投入】
                                 LLM/VLM：有评测结果？
                                 T2I LoRA：有示例图 + 触发词？
                                   是 → ✅ 优质
                                   否 ↓
                                 有任何值得关注的信号？
                                   是 → ⏳ 待跟踪
                                   否 → 不计入
```

**等级定义：**

| 等级 | 定义 |
|------|------|
| **优质** | 明确满足至少一条有实质证据的维度 |
| **待跟踪** | 有至少一个值得关注的正向信号，但不满足任何一条优质维度，标记后定期人工复查 |
| **不计入** | 没有任何维度的有效证据 |

---

## 七、这套标准不判断什么

这套标准衡量的是**影响力与真实性**，不是技术质量或价值取向。

- 一个去审查版（Uncensored）微调有大量下载，按此标准是优质的
- 一个小众领域的精细微调只有 80 下载但卡片写清楚了用途，按此标准是待跟踪的
- 两者都不是"更重要"或"更有价值"的判断——这套标准不做这层区分

---

## 八、标准的时效性

下载量门槛基于 2026-04-24 全量数据推导，反映当前市场结构。量化门槛的核心参数是几何均值（89）和对数标准差（0.96）；FT 门槛的核心参数是真实使用人群（3+下载）的 P75（61）。市场格局短期内不会大幅变化，门槛本身相对稳定。建议每季度复查一次，用最新数据重新验证几何均值和真实使用人群 P75 是否有显著偏移。
